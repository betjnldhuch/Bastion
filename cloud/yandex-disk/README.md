# Раздача архивов игры через Яндекс Диск

Бесплатно и без карты. Лаунчеры (ПК и Android) получают по ссылке Диска
временную прямую ссылку через API Диска (`/v1/disk/public/resources/download`)
и скачивают архив. Ссылка нигде не публикуется, она вшита в лаунчер из секретов.

## 1. Залей архивы
На disk.yandex.ru загрузи два ZIP: архив для телефона и архив для ПК
(внутри `gta_sa.exe` и `samp.exe`). Папки целиком не заливай — только ZIP.

## 2. Ссылки
Правой кнопкой по файлу → **Поделиться** → **Скопировать ссылку**.
Ссылка вида `https://disk.yandex.ru/d/AbCdEf123`. Права — только просмотр.

## 3. Секреты GitHub
Settings → Secrets and variables → Actions:

| Имя | Значение |
|---|---|
| `BASTION_GAME_URL` | ссылка Диска на архив для телефона |
| `BASTION_GAME_MD5` | MD5 архива для телефона |
| `BASTION_PC_GAME_URL` | ссылка Диска на архив для ПК |
| `BASTION_PC_GAME_MD5` | MD5 архива для ПК |

MD5: `Get-FileHash "архив.zip" -Algorithm MD5`. Секреты `BASTION_B2_*` для Диска не нужны.

## 4. Пересборка
Actions → **Build Bastion PC launcher** и **Build single Bastion Android APK** → Run workflow.

## Ограничения
- Кто узнает ссылку, сможет скачать файл (как и с ключом внутри лаунчера).
- Если файл качают очень часто, Яндекс может временно ограничить скачивание;
  лаунчер тогда покажет «Яндекс Диск временно ограничил скачивание».
- Заменил архив на Диске — ссылка остаётся, обнови только MD5 и пересобери.
