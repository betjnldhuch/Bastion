# Форум Bastion Online

Свой форум проекта. Работает на том же компьютере, что и игровой сервер, и **входит по игровому аккаунту**:
ник и пароль те же, что в игре, отдельной регистрации нет. Форум только **читает** базу сервера
`scriptfiles/rp.db` и ничего в ней не меняет.

## Что умеет

| Что | Как работает |
|---|---|
| Вход | Ник `Имя_Фамилия` и пароль из игры (проверка как `SHA256_Hash` в open.mp). Выбор сервера Peace / War |
| Разделы | Новости, правила, помощь, жалобы на игроков и администрацию, обжалования, заявки в администрацию, заявления во все 5 фракций, общение, барахолка, предложения, баг-репорты |
| Формы | Жалобы, обжалования, заявки и баг-репорты открываются с готовым шаблоном. Пустой шаблон отправить нельзя |
| Статусы | «На рассмотрении», «Одобрено», «Отказано», «Закрыто». Решение пишется в тему и закрывает её. Фильтр по статусам |
| Права из игры | Админка в игре = права на форуме (`moderator_level`, `admin_level` в forum.ini). Лидер и зам. фракции (ранг 9–10) разбирают заявления своей фракции |
| Баны | Страница `/bans` из игровой базы. Забаненный в игре может зайти и написать только в «Обжалование наказаний» |
| Профиль | Уровень, фракция и ранг, админка, дата регистрации в игре, темы, подпись |
| Администрация | Страница `/team`: админы и лидеры фракций, берётся из базы сервера |
| Модерация | Закрепить, закрыть, перенести, удалить тему и сообщения, блокировка на форуме, журнал `/modlog` |
| Статус серверов | Онлайн и число игроков на главной (SA-MP query, раз в 30 секунд) |
| Для лаунчеров | `/news.txt` — новости в формате `launcher/news.txt`; `/api/status.json` — статус серверов и новости |
| BB-коды | `[b] [i] [u] [s] [quote] [spoiler] [url] [img] [code] [color] [center] [list]`, кнопки над полем ввода |
| Телефон | Вёрстка подстраивается под экран телефона |

## Как запустить

1. Поставь **Python 3.9 или новее** с [python.org](https://www.python.org/downloads/).
   При установке отметь галочку **Add Python to PATH**. Больше ничего ставить не нужно.
2. Скопируй папку `forum` куда угодно, например в `C:\openmp\forum`.
3. Открой `forum.ini` и впиши путь к базе сервера в `db` (по умолчанию `C:\openmp\Server\scriptfiles\rp.db`).
   Если сервер один, удали блок `[server:war]`.
4. В `owners` впиши свой ник — получишь полные права на форуме.
5. Запусти `start.bat` и открой в браузере <http://127.0.0.1:8080>.

**Посмотреть без сервера:** запусти `start-demo.bat`. Форум создаст тестовую базу с игроками и темами.
Вход: `Pal_Layach` / `demo123` (админ), `Ivan_Petrov` / `demo123` (игрок), `John_Smith` (лидер LSPD),
`Cheater_Boy` (забанен). Демо-данные лежат отдельно в `data/demo` и не смешиваются с настоящими.

## Как открыть форум другим

- **Radmin VPN / локальная сеть:** форум сразу доступен по адресу `http://<твой IP>:8080`.
  Разреши Python в брандмауэре Windows, когда он спросит.
- **Интернет:** проброс порта 8080 на роутере, или туннель (Cloudflare Tunnel, ngrok).
  Если открываешь по `https://`, впиши этот адрес в `public_url`, тогда cookie станут защищёнными.
- В лаунчере ПК (`launcher/launcher.ini`) впиши адрес форума в `site =`, появится кнопка «Сайт».
  В `news_url =` можно вписать `http://<адрес форума>/news.txt`, и новости в лаунчере будут браться с форума.

## Где что лежит

| Файл | Что это |
|---|---|
| `forum.py` | Запуск |
| `forum.ini` | Настройки |
| `app/server.py` | Страницы, вход, права |
| `app/views.py` | HTML-шаблоны |
| `app/storage.py` | База форума `data/forum.db`, разделы и шаблоны форм |
| `app/game.py` | Чтение `rp.db`, проверка пароля, статус сервера, фракции и ранги |
| `app/markup.py` | BB-коды |
| `static/` | Стили, скрипт, шрифт |
| `tests/` | Проверки: `python -m unittest discover -s tests` |

Все данные форума (темы, сообщения, сессии) — в `data/forum.db`. Для резервной копии достаточно
скопировать папку `data`. Разделы создаются при первом запуске; переименовать их или добавить новые можно
в `data/forum.db` (таблицы `categories` и `forums`) или в `default_structure()` в `app/storage.py` до первого запуска.

Если в моде поменяются названия фракций или рангов, обнови `FACTIONS` и `RANK_NAMES` в `app/game.py`.
