BASTION ONLINE — ЛАУНЧЕР
========================

Что умеет:
 • тёмный минималистичный дизайн, окно без рамки (таскается за фон);
 • показывает сервера Bastion Peace и Bastion War, их онлайн и пинг (обновляется каждые 10 сек);
 • запоминает ник и проверяет, что он вида Имя_Фамилия;
 • сам находит папку GTA (берёт из настроек SA-MP) или даёт выбрать через «Обзор…»;
 • перед запуском ищет моды (.asi, cleo, modloader и т.п.), из-за которых SA-MP вылетает,
   и предлагает убрать их в папку _off (ничего не удаляет, можно вернуть обратно);
 • кнопка «ИГРАТЬ» (или двойной клик по серверу) запускает SA-MP и сразу подключает к серверу.

УСТАНОВКА ДЛЯ ИГРОКА (ОДИН ФАЙЛ)
 • ПК: https://github.com/betjnldhuch/bastion/releases/latest/download/BastionSetup.exe
   Ставит лаунчер в %LocalAppData%\Bastion Online\Launcher, ярлык на рабочем столе, сразу запускает.
   При первом запуске лаунчер сам предлагает поставить игру в %LocalAppData%\Bastion Online\Game.
 • Телефон: https://github.com/betjnldhuch/bastion/releases/latest/download/Bastion.apk
 • Лаунчер, запущенный из любого другого места (Загрузки, рабочий стол, Program Files, прямо из zip),
   сам переезжает в %LocalAppData%\Bastion Online\Launcher и делает ярлык. Шрифт и пакет FPS вшиты в exe.
   Не переезжать (своя сборка): portable = true в launcher.ini рядом с exe.

КАК ЗАПУСТИТЬ
1. Распакуй папку BastionLauncher куда угодно (например, на Рабочий стол).
2. Запусти BastionLauncher.exe.
   Если Windows покажет синее окно «Windows защитила ваш компьютер» —
   нажми «Подробнее» → «Выполнить в любом случае». Это потому что у exe нет платной подписи.
3. Впиши ник, проверь папку GTA (в ней должны быть gta_sa.exe и samp.exe), выбери сервер, жми ИГРАТЬ.

АДРЕСА СЕРВЕРОВ — файл launcher.ini (открывается Блокнотом)
   server = Bastion Peace | 127.0.0.1 | 7777 | описание
 • 127.0.0.1 — сервер на твоём же компьютере.
 • Для друзей через Radmin VPN — впиши свой IP из Radmin (вида 26.x.x.x) и отдай им эту папку.
 • Когда будет хостинг — впиши его адрес.
 • Bastion War стоит на порту 7778: пока второго сервера нет, он будет «выключен», это нормально.
   Не нужен — удали строку или поставь ; в начале.
 • site = ссылка на Discord/сайт — появится кнопка «Сайт».

ЕСЛИ ЧТО-ТО НЕ ТАК
 • «Сервер выключен», хотя он запущен: проверь порт в launcher.ini (как в config.json сервера)
   и что брандмауэр Windows не блокирует omp-server.
 • Не получилось перенести моды: запусти лаунчер правой кнопкой → «Запуск от имени администратора»
   (нужно, если игра лежит в Program Files).

НОВОСТИ И ФОН
 • news.txt — новости на главном экране: дата | заголовок | текст (одна строка = одна новость).
 • Новости, список серверов и обновления лаунчер сам берёт из сети (папка launcher на сервере
   раздачи игры). news.txt и строки server в launcher.ini нужны, когда сети нет.
 • Вышла новая версия — лаунчер предложит обновиться и перезапустится сам. launcher.ini не меняется.
 • Положи background.jpg (1000x600) рядом с exe — он станет фоном вместо стандартного.
 • «Настройки» (вверху справа): папка GTA, лимит FPS, строк в чате, время в чате,
   многоядерность (это пишется в настройки самого SA-MP), проверка модов
   и «закрывать лаунчер после запуска».
 • FPS выше 90 (120 / 144 / 165): нужен пакет FPS в папке fps — что туда положить,
   написано в fps\README.txt. Без него лаунчер запустит игру с 90 FPS.
 • Папку fonts не удаляй — там фирменный шрифт заголовков (Russo One, бесплатный).

ДЛЯ ПРАВОК
 В папке source лежит исходники Core.cs, Ui.cs, Installer.cs, Updater.cs (дизайн — в Ui.cs). Поменял что-то — запусти source\build.bat,
 он пересоберёт exe встроенным в Windows компилятором (ничего ставить не нужно).

ФАЙЛЫ ИГРЫ (КЛИЕНТСКИЙ ПАКЕТ)
 • Перед запуском лаунчер сверяет файлы Bastion (HUD, модели, карта) с сервером и докачивает
   только изменившиеся. Оригиналы сохраняются в папке игры: _bastion_backup.
 • «Настройки» → «Проверить файлы» — сверка всех файлов игры с эталоном (размер + CRC32 из архива
   игры) и пакета Bastion; повреждённые и пропавшие лаунчер заменит из архива, моды и настройки не трогает.
 • «Настройки» → «Переустановить» — скачать игру начисто и поставить заново (если проверка не помогла).
 • Для админа: файлы кладутся в папку pack-tool\pack так же, как в папке GTA, затем
   make-client-pack.ps1 -Version N; client-pack.json и папку pack залить в launcher/ на сервер раздачи.

КНОПКИ ФОРУМ / ДОНАТ
 • Строки link = ФОРУМ | https://… в servers.ini на сервере раздачи (или в launcher.ini).
