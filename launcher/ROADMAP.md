## Общая схема

Оба лаунчера берут живые данные из репозитория, а не из сборки:

- `launcher/remote/servers.ini` — список серверов (`server = Имя | адрес | порт | описание`).
  ПК: ключ `servers_url` в `launcher.ini`, кэш `servers.cache` на случай без сети.
- `launcher/remote/news.txt` — новости (ПК: `news_url`).

Пока сервер хостится с ПК, адреса локальные, поэтому `servers_url` выключен.
Когда появится постоянный адрес (хостинг, белый IP или домен), достаточно
вписать его в `remote/servers.ini` и включить `servers_url` — новую версию
лаунчера раздавать не придётся.

## План

### Этап 1 — инфраструктура (ветка `feature/launcher-pc`)
- [x] Сборка ПК-лаунчера в GitHub Actions, готовый ZIP в artifact.
- [x] Общий список серверов по ссылке с кэшем.
- [ ] Новости по умолчанию из `remote/news.txt`.

### Этап 2 — Android (ветка `feature/launcher-mobile`)
- [ ] Тот же `servers_url` и `news_url`, что у ПК (с кэшем, без сети — `assets/`).
- [ ] Ссылка на game.zip из удалённого конфига вместо жёсткого `192.168.31.182`.
- [ ] Проверка установки на реальном телефоне: установка ZIP → вход на сервер.

### Этап 3 — обновления
- [ ] ПК: проверка версии лаунчера (`remote/version.ini`) и скачивание нового ZIP.
- [ ] Android: проверка `versionCode` и предложение скачать новый APK.
- [ ] ПК: установщик клиентского пакета (модели, звуки, HUD Bastion) с проверкой SHA-256,
      по образцу Android-установщика.

### Этап 4 — аккаунт и форум
- [ ] Кнопки «Форум» и «Донат» из удалённого конфига (после треда форума).
- [ ] Показ ника/статуса аккаунта, когда у сервера появится API.

## Риски
- Клиент SAMP-Mobile без лицензии и содержит `libGame.so` Rockstar — публичная раздача APK
  требует согласия авторов (см. `mobile/SAMP-MOBILE-INTEGRATION.md`).
- ПК-лаунчер без подписи кода: Windows SmartScreen предупреждает при первом запуске.
