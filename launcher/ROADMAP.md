## Общая схема

Оба лаунчера берут живые данные из репозитория, а не из сборки:

- `launcher/remote/servers.ini` — список серверов (`server = Имя | адрес | порт | описание`).
  ПК: ключ `servers_url` в `launcher.ini`, кэш `servers.cache` на случай без сети.
- `launcher/remote/news.txt` — новости (ПК: `news_url`).

Пока сервер хостится с ПК, адреса локальные, поэтому `servers_url` выключен.
Когда появится постоянный адрес (хостинг, белый IP или домен), достаточно
вписать его в `remote/servers.ini` и включить `servers_url` — новую версию
лаунчера раздавать не придётся.

### Клиентский пакет HUD и карты (отложено вместе с лаунчером)
Перенесено из треда HUD: весь клиентский HUD и карта ставятся через ПК-лаунчер.
Серверная часть HUD (панель статуса, спидометр, окно сумки) сделана отдельно и от этого не зависит.

Что входит в пакет:
- `models/hud.txd` — рамка радара, иконки на карте и радаре, иконки HUD;
- `models/fonts.txd` — цифры HUD и кириллица, чтобы надписи сервера на экране были русскими;
- `radar00.txd` … `radar143.txd` внутри `models/gta3.img` — перерисованная карта и радар
  (по оригинальным тайлам, чтобы совпадала с миром);
- позже: ASI-плагин для цветов полосок здоровья и брони (они зашиты в exe);
- вторым этапом: HUD на телефоне.

Нужно от владельца: `models/hud.txd`, `models/fonts.txd`, `models/gta3.img`
(или скрипт, который вытащит тайлы на его ПК), по желанию лист-макет стиля.

Манифест `launcher/remote/client-pack.json` (или `client_pack_url` в `launcher.ini`):

```json
{
  "version": 1,
  "product": "Bastion PC client pack",
  "files": [
    { "path": "models/hud.txd", "url": "https://…/hud.txd", "size": 123456, "sha256": "…" },
    { "path": "models/gta3.img", "name": "radar00.txd", "url": "https://…/radar00.txd", "size": 8192, "sha256": "…" }
  ]
}
```

- `version` растёт при каждом изменении пакета; лаунчер помнит установленную версию и предлагает обновление.
- `path` — относительно папки GTA, только латиница, цифры, `._-/`, без `..`; `url` только https;
  `sha256` — строчными. Скачивание во временный файл, проверка размера и SHA-256, затем замена.
- Обычный файл: оригинал один раз сохраняется в `_bastion_backup/<path>`.
- Запись внутри IMG (`name`, до 23 символов): только IMG v2 (VER2). Если новые данные помещаются
  в секторы записи — запись на месте, иначе дописываются в конец архива и обновляются offset и size.
  Оригинал записи сохраняется в `_bastion_backup/<path>/<name>`, а не весь архив.
  Запись с тем же SHA-256 пропускается.
- Ключ `X-Bastion-Key` отправляется, только если хост `url` совпадает с хостом архива игры
  (R2 за Worker); файлы из GitHub Releases тоже подходят.
