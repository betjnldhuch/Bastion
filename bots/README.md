# Боты Bastion Online: ВКонтакте и Telegram

Один скрипт на Python запускает сразу двух ботов. Работает **на том же ПК, что и игровой сервер**,
рядом с форумом: читает базу `scriptfiles/rp.db` и через неё общается с модом.
Ничего, кроме Python 3.9+, ставить не нужно. Белый IP, сайт и домен не нужны.

## Что умеют боты

| Команда | Что делает |
|---|---|
| `/link 123456` (или просто код) | Привязать игровой аккаунт. Код игрок получает в игре командой `/bot`, живёт 10 минут |
| `/me` | Мой персонаж: уровень, деньги и банк, работа, фракция и ранг, розыск, бан |
| `/online` | Какие сервера включены, сколько игроков и их ники |
| `/top` | Топ-10 игроков по уровню |
| `/notify` | Включить/выключить уведомления |
| `/notme` | «Это не я»: выкинуть свой аккаунт с сервера |
| `/restore` | Забыл пароль: бот присылает новый, мод сразу его ставит |
| `/unlink Ник` | Отвязать аккаунт |
| `/news текст` | Рассылка всем привязанным (только админы с `news_level` в bots.ini) |

**Уведомления из игры** приходят сами: вход в аккаунт (с кнопками «Это не я» и «Новый пароль»),
3 неверных пароля подряд, бан. Добавить своё уведомление в моде — одна строка:
`Social_Notify(Player[playerid][pDbId], "Текст");`

К одному ВК/ТГ можно привязать несколько аккаунтов (и с Peace, и с War). Боты отвечают только в личных сообщениях.

## Как бот связан с игрой

```
Игрок в игре: /bot  ->  мод пишет код в social_codes
Игрок боту: /link код  ->  бот находит код, пишет связь в social_links
Мод: вход в аккаунт  ->  строка в bot_outbox  ->  бот раз в 3 сек забирает и отправляет в ВК/ТГ
Бот: /restore или /notme  ->  строка в bot_actions  ->  мод раз в 3 сек выполняет (новый пароль, кик)
```

Таблицы создаются сами. Пароли бот **не трогает**: он только просит мод, а мод хеширует пароль так же, как при регистрации.

## Как устроены боты ВКонтакте (простыми словами)

1. **Бот в ВК — это сообщество (группа).** Отдельного «аккаунта бота» нет: игроки пишут в сообщения
   группы, а отвечает им наша программа от имени группы.
2. **Токен (ключ доступа)** — это пароль, с которым программа действует от имени группы.
   Кто знает токен, может писать от имени группы, поэтому его никому не показываем и не кладём на GitHub.
3. **Как бот узнаёт о новых сообщениях.** У ВК два способа:
   - **Long Poll** (мы используем его). Программа сама спрашивает ВК: «есть новые сообщения?» и ждёт ответа
     до 25 секунд. Пришло сообщение — ВК отвечает мгновенно. Работает с любого домашнего ПК.
   - **Callback API.** ВК сам присылает сообщения на твой сайт. Нужны свой адрес в интернете и HTTPS, поэтому нам не подходит.
4. **Ответ** программа отправляет методом `messages.send`. Кнопки снизу — это «клавиатура бота» ВК.
5. ВК разрешает писать человеку, только если он сам написал группе или разрешил сообщения.
   Поэтому уведомления приходят только тем, кто привязал аккаунт (а для этого он уже написал боту).

### Настройка ВК по шагам

1. vk.com → **Сообщества → Создать сообщество** (тип «Группа по интересам» или «Бренд», название Bastion Online).
2. В группе: **Управление → Сообщения** → «Сообщения сообщества»: **Включены**.
3. **Управление → Сообщения → Настройки для бота** → «Возможности ботов»: **Включены**,
   «Добавить кнопку "Начать"»: да.
4. **Управление → Работа с API → Long Poll API** → «Long Poll API»: **Включено**, версия **5.199**.
   Там же вкладка **«Типы событий»** → отметь **«Входящее сообщение»**.
5. **Управление → Работа с API → Ключи доступа → Создать ключ**, галочки «Управление сообществом»
   и «Сообщения сообщества». Скопируй ключ — это `token`.
6. ID группы (`group_id`) — число из адреса `vk.com/club123456789` или в разделе «Long Poll API».

## Настройка Telegram

1. В Telegram открой **@BotFather** → `/newbot` → имя (Bastion Online) → адрес (например `bastion_rp_bot`).
2. BotFather пришлёт токен вида `123456789:AAE...` — это `token`.
3. Меню команд бот поставит себе сам при запуске.

## Как запустить

1. Скопируй папку `bots` на ПК-сервер, например в `C:\openmp\bots`.
2. Открой `bots.ini`: впиши токены, `group_id`, поставь `enabled = on` и проверь пути `db` к `rp.db`.
   Если сервер один, удали блок `[server:war]`.
3. Запусти `start.bat`. В окне должно быть `[vk] бот ВКонтакте запущен` и `[tg] бот Telegram запущен`.
4. Проверь: в игре `/bot`, затем напиши боту код.

Бот должен работать всё время вместе с сервером (окно не закрывать). Если сервер выключен,
боты продолжают отвечать (`/online` покажет «выключен»), а новый пароль применится при запуске сервера.

## Файлы

| Файл | Что это |
|---|---|
| `bot.py` | Запуск, рассылка уведомлений из игры |
| `bots.ini` | Настройки и токены |
| `app/logic.py` | Все команды (общие для ВК и ТГ) |
| `app/vk.py`, `app/tg.py` | Связь с ВКонтакте и Telegram |
| `app/db.py` | Таблицы ботов в `rp.db` |
| `app/query.py` | Онлайн сервера (SA-MP query) |
| `tests/` | Проверки: `python -m unittest discover -s tests` |
| `../server/gamemodes/bastion/social.inc` | Часть в моде: `/bot`, уведомления, смена пароля |
