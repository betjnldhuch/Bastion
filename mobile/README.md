# Bastion Online для Android

Android-лаунчер Bastion Online: выбор сервера, онлайн/пинг, ник, новости, настройки и установщик клиентских ресурсов.

| Папка | Назначение |
|---|---|
| `launcher/` | Android-лаунчер на Java |
| `installer/` | Манифест и инструкция по публикации файлов клиента |

## Сборка

- Android Studio: открыть `mobile/launcher`.
- Linux: запустить `mobile/launcher/build.sh`.
- APK: `mobile/launcher/build/BastionOnline.apk`.

## Установщик клиента

В **Настройки → Установить файлы клиента** лаунчер загружает список из
`mobile/installer/manifest.json`, скачивает перечисленные файлы, проверяет размер и SHA-256,
а затем устанавливает их в:

`Android/data/online.bastion.launcher/files/client/`

Манифест пока пустой: в репозитории ещё нет опубликованного набора Android-клиента,
который Bastion имеет право распространять. Добавлять сюда серверный архив
`Bastion-server-mod.zip` нельзя: он содержит Pawn gamemode и include-файлы для сервера,
а не Android-клиент, HUD или игровые текстуры.

Установщик не требует установленного GTA SA и не проверяет пакет Google Play.
Диагностика показывает только сведения об устройстве.

## Важно о базе клиента

Официальный SampDroid — отдельный закрытый Android-лаунчер/проект, а публичный репозиторий
`shadergz/sampdroid` содержит Android-плагин, а не готовый самостоятельный игровой клиент.
Поэтому сам установщик Bastion сделан универсальным: он принимает собственные или
разрешённые к распространению файлы клиента по манифесту. Игровые данные GTA SA и чужие APK
в репозиторий Bastion не копируются.
