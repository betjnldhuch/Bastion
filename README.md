# Bastion Online

Свой онлайн-сервер для GTA San Andreas Multiplayer на open.mp.

## Что здесь лежит

| Папка | Что это |
|---|---|
| `server/gamemodes/` | Мод сервера: `rp.pwn` и модули в `bastion/` (аккаунты, машины, дома, работы, фракции, админка) |
| `server/README.md` | Подробная инструкция: установка, компиляция, команды, как устроен код |
| `launcher/` | Лаунчер для игроков (C#, Windows): исходник, `build.bat`, настройки `launcher.ini` |
| `mobile/` | Версия для Android: лаунчер (первая сборка), дальше свой клиент |

## Как поставить мод на сервер

1. Нажми зелёную кнопку **Code → Download ZIP** и распакуй архив.
2. Скопируй папку `server/gamemodes` в `C:\openmp\Server` с заменой файлов.
3. Открой `gamemodes/rp.pwn` в Qawno и нажми Fn+F5.
4. Запусти сервер.

Файлы `.pwn` и `.inc` сохранены в кодировке **Windows-1251**, поэтому на сайте GitHub русский текст в них может выглядеть кракозябрами. В Qawno и в игре всё нормально.

## Два сервера

Один код на два сервера (пока без различий): **Bastion Online: Peace** (админы помогают игрокам) и **Bastion Online: War** (закон сильного, админы только банят читеров).
