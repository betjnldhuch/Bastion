**Чего в бэкапе нет и что сохранить самому:**
- **База игроков `scriptfiles/rp.db`** — она только у тебя на ПК. Скопируй `rp.db` и свежий `scriptfiles/rp_backup_*.db` (стартер и мод делают их сами, мод хранит 14 последних) на флешку/в облако. Для автокопии вне ПК см. `server/README.md` → «Автобэкап в GitHub».
- `config.json` сервера (пароль RCON, название, слоты) — скопируй рядом с базой.
- Секреты GitHub Actions (значения не хранятся нигде, кроме настроек репо): `BASTION_GH_TOKEN`, `BASTION_DOWNLOAD_KEY`, `BASTION_GAME_URL`, `BASTION_GAME_MD5`, `BASTION_PC_GAME_URL`, `BASTION_PC_GAME_MD5`, `BASTION_B2_KEY_ID`, `BASTION_B2_KEY`. Запиши их значения себе в надёжное место.
- `game.zip` (файлы GTA для установщика) — лежит в облаке (R2/B2/Я.Диск, см. `cloud/`), в бэкап не входит из-за размера.
- Клиент SAMP-Mobile — submodule `mobile/samp-mobile` (https://github.com/kuzia15/SAMP-Mobile, ветка GTA-2.11); в bundle только ссылка на него.

## 3. Восстановление с нуля

### Репозиторий
```
git clone bastion-full.bundle bastion
cd bastion
git remote set-url origin https://github.com/<ник>/bastion.git
git push --all origin && git push --tags origin
git submodule update --init   # клиент SAMP-Mobile
```
Затем в Settings → Secrets → Actions заново внеси секреты из списка выше.

### Сервер (ПК с Windows)
1. Скачай open.mp Server для Windows (open.mp/download), распакуй, например, в `C:\openmp\Server`.
2. Распакуй `Bastion-gamemodes-82d121d.zip` в `gamemodes` (должны быть `rp.amx`, `rp.pwn`, `bastion\`).
3. Положи свой сохранённый `config.json` (или настрой: `"main_scripts": ["rp 1"]`, `max_players` ≤ 1000, свой пароль RCON).
4. Положи сохранённую `rp.db` в `scriptfiles\` (удали рядом `rp.db-wal`/`rp.db-shm`, если есть).
5. Распакуй `BastionServer.zip` рядом с `omp-server.exe`, запусти `BastionServer.exe` → СТАРТ.
6. Без базы сервер создаст новую пустую; админку выдать: `/rcon login <пароль>`, `/makeadmin <id> 7`.

### Клиент
- **ПК:** распакуй `BastionLauncher-PC-82d121d.zip`, в `launcher.ini` проверь адреса серверов, запусти `BastionLauncher.exe`. Нужна GTA SA 1.0 + SA-MP 0.3.7.
- **Телефон:** установи `Bastion-Launcher-82d121d-debug.apk` (Android 9+, ARM64), установщик внутри скачает game.zip.

### Пересборка из исходников
- Мод: Qawno → открыть `rp.pwn` → F5 (или workflow `server-build.yml`).
- Всё сразу: push в `main` → `release-main.yml` соберёт APK, ПК-лаунчер и rp.amx в новый релиз.
- Графика клиента: `python client-mods/tools/build_*.py`, картинки-исходники — в `bastion-graphics.zip`.
