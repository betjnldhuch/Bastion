# Хостинг Bastion Peace

Публичный адрес: `80.47.6.18:25174`. War пока не запускается.

- На хостинге: open.mp, `gamemodes/rp.amx`, `scriptfiles/` (перенести существующую SQLite после остановки старого сервера). В панели проверить назначенный UDP-порт, внутренний порт и привязку адреса. В `config.json` использовать параметры панели; `pawn.main_scripts = ["rp 1"]`, RCON отключить, если не нужен. Публичный IP не обязательно является локальным адресом bind.
- Главный список серверов для новых ПК и Android сборок — `launcher/remote/servers.ini` в ветке main, доступен по HTTPS. ПК сохраняет возможность задать свой `servers_url`. Новости и игровые архивы по-прежнему раздаются отдельно. Старые сборки, использующие Worker, требуют загрузить туда тот же файл (`launcher/servers.ini` в R2), либо обновить лаунчер. При необходимости в старом ПК лаунчере задать `servers_url = https://raw.githubusercontent.com/betjnldhuch/Bastion/main/launcher/remote/servers.ini`.
- Форум и боты: адрес для UDP-опроса обновлён, но `db` в их ini требуется настроить на реальную базу. Если игровой хостинг не разрешает запуск Python рядом с SQLite, нужна отдельная серверная интеграция; не публиковать rp.db и не использовать FTP-копию как рабочую базу для записи.
- Windows-стартер и Windows-бэкапы на Linux-хостинге не работают; использовать панель и резервные копии хостинга. Хранить копии базы отдельно.
- После слияния проверить сборки ПК и APK и реальный вход с внешней сети. В репозитории не меняются настройки живой панели, пароли и секреты.
