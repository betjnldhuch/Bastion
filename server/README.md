# Bastion Online — свой сервер GTA SA:MP с нуля

Это стартовый RolePlay-мод для **open.mp** (современный сервер для SA-MP, полностью совместим с обычным клиентом SA-MP 0.3.7). Написан на языке **Pawn**, данные хранятся в базе **SQLite**, никаких плагинов ставить не нужно.

Что уже есть на сервере:

| Система | Что умеет |
|---|---|
| Аккаунты | Регистрация и вход через окна, пароль хранится в виде хеша SHA-256 с солью, 3 попытки ввода, выбор пола, ник только `Имя_Фамилия` |
| Сохранение | Деньги, уровень, опыт, скин, админка, работа, дом, машина пишутся в `scriptfiles/rp.db` |
| RP-чат | Локальный чат (слышно в радиусе 20 м), `/me /do /try /s /b /pm`, текст над головой |
| Экономика | Деньги считает сервер (читерские деньги не работают), PayDay каждый час: зарплата и опыт, рост уровня |
| Работы | Грузчик в порту (носишь ящики), развозчик пиццы (на мопеде по адресам) |
| Транспорт | Двигатель заводится вручную, общественные машины, автосалон, своя машина с парковкой и замком |
| Дома | Покупка и продажа, вход в интерьер, замок, спавн у своего дома, админ может создавать новые дома |
| Админка | 5 уровней, выдача через RCON, телепорты, кик, создание машин, деньги, здоровье, скины |
| Смерть | Появляешься в больнице, лечение стоит $100 |

---

## 1. Что нужно установить

1. **GTA San Andreas версии 1.0** (именно 1.0, иначе SA-MP не запустится; если игра из Steam, её нужно откатить до 1.0 — гугли «downgrader GTA SA»).
2. **Клиент SA-MP 0.3.7** с сайта [sa-mp.mp](https://sa-mp.mp) или **лаунчер open.mp** с [open.mp/download](https://open.mp/download). Это то, чем ты подключаешься к серверам.
3. **Сервер open.mp для Windows** с [open.mp/download](https://open.mp/download) (раздел Server). В архиве уже есть всё нужное: сам сервер `omp-server.exe`, редактор и компилятор **Qawno**, include-файлы.
4. **Notepad++** ([notepad-plus-plus.org](https://notepad-plus-plus.org)) — удобно редактировать код и он правильно держит кодировку Windows-1251 (см. раздел 9).
5. По желанию: **DB Browser for SQLite** ([sqlitebrowser.org](https://sqlitebrowser.org)) — чтобы смотреть и править базу игроков.

## 2. Установка мода

1. Распакуй сервер open.mp, например в `C:\openmp\`. Внутри будут папки `gamemodes`, `qawno`, `scriptfiles` и файл `config.json`.
2. Скопируй из этого архива в `C:\openmp\gamemodes\`:
   - файл `rp.pwn`
   - папку `bastion` целиком (в ней 10 файлов `.inc`)

   Должно получиться `C:\openmp\gamemodes\rp.pwn` и `C:\openmp\gamemodes\bastion\config.inc` и т.д.
3. Открой `C:\openmp\config.json` в Notepad++ и поменяй эти поля (остальное не трогай):

   ```json
   "name": "Bastion Online | Peace",
   "max_players": 100,
   "pawn": {
       "legacy_plugins": [],
       "main_scripts": ["rp 1"],
       "side_scripts": []
   },
   "rcon": {
       "allow_teleport": false,
       "enable": false,
       "password": "придумай_сложный_пароль"
   },
   ```

   Главное: в `main_scripts` должно быть `"rp 1"` (это значит «запусти gamemodes/rp.amx»), а `password` в блоке `rcon` не должен оставаться `changeme`, иначе сервер не запустится. `max_players` не больше 100 (так задано в начале `rp.pwn`).

## 3. Компиляция (превращаем код в `rp.amx`)

Сервер не читает `.pwn` напрямую, его нужно скомпилировать.

1. Запусти `C:\openmp\qawno\qawno.exe`.
2. File → Open → `C:\openmp\gamemodes\rp.pwn`.
3. Нажми **F5**.
4. Внизу появится вывод компилятора. Если последняя строка просто `Pawn compiler 3.10.x` без ошибок — готово, рядом с `rp.pwn` появился `rp.amx`.

Что значит вывод:
- **error** — код не собрался, `.amx` не создан. Нужно исправить.
- **warning** — собралось, но что-то подозрительно. Работать будет, но лучше разобраться.

> Мод собран под include-файлы open.mp, но у меня не было возможности запустить компилятор у себя. Если при F5 будут ошибки или предупреждения, нажми **Ctrl+E** в Qawno (копирует весь вывод), пришли мне — исправлю.

## 4. Запуск

1. Запусти `C:\openmp\omp-server.exe`.
2. В консоли должно быть примерно:
   ```
   [DB] Database opened.
   [Houses] Default houses created.
   [Houses] Loaded 3 houses.
     |  Bastion Online loaded  |
   ```
3. В папке `scriptfiles` появится `rp.db` — это база с аккаунтами, домами и машинами.

Если Windows спросит про брандмауэр — разреши доступ.

## 5. Подключение к своему серверу

1. Открой клиент SA-MP (или лаунчер open.mp).
2. Впиши ник в формате **Имя_Фамилия**, например `Ivan_Petrov` (латиницей, с подчёркиванием).
3. Добавь сервер: **127.0.0.1:7777** (это «мой же компьютер»).
4. Подключайся. Появится окно регистрации: придумай пароль, выбери пол — и ты на улице Grove Street с $5000.

## 6. Как стать админом

1. В игре введи `/rcon login придумай_сложный_пароль` (пароль из `config.json`).
2. Введи `/makeadmin 0 5` — где `0` это твой id (он виден в TAB). Уровень 5 — владелец.
3. Админка сохраняется в базе, в следующий раз RCON не нужен.

## 7. Как играть: команды и места

**Общее:** `/help` — все команды, `/stats` — статистика, `/time`, `/pay [id] [сумма]`, `/admins`, `/report [текст]` — вопрос или жалоба админам (без текста откроется окно).

**RP-чат:** обычный текст слышат только те, кто рядом.
- `/me достал телефон` → *Ivan Petrov достал телефон*
- `/do На столе лежит ключ.` → описание ситуации
- `/try открыть дверь` → случайно «удачно» или «неудачно»
- `/s` — крик, `/b` — OOC (не по роли), `/pm [id] [текст]` — личное сообщение.

**Работы:** подойди к значку футболки, введи `/getjob`, затем `/work`.
- **Грузчик** — порт Ocean Docks. Идёшь к красному маркеру, берёшь ящик, несёшь на склад: $120 за ящик.
- **Развозчик пиццы** — пиццерия в Idlewood. Садишься на мопед Pizzaboy рядом, `/work`, везёшь по адресам: $80–150 за заказ.
- `/work` ещё раз — закончить смену, `/quitjob` — уволиться.

**Транспорт:** `/engine` — завести/заглушить. Автосалон Coutt & Schutz (значок $): `/buycar`. Купленную машину поставь, где удобно, и введи `/park` — там она будет появляться. `/lock` — замок, `/sellcar` — продать в салоне за полцены.

**Дома:** зелёный домик — продаётся (`/buyhouse`), синий — занят. `/enter` у двери, `/exit` внутри у двери, `/lock` — замок, `/sellhouse` — продать за полцены. Если у тебя есть дом, спавнишься у него.

**Фракции** (все команды в игре: `/fhelp`):

| № | Фракция | База | Что умеет |
|---|---|---|---|
| 1 | Полиция LSPD | участок на Pershing Square | розыск, наручники, арест, тюрьма |
| 2 | Больница LS (EMS) | All Saints | лечит игроков за $200 |
| 3 | Grove Street Families | Grove Street | банда |
| 4 | The Ballas | мотель Jefferson | банда |
| 5 | Varrios Los Aztecas | El Corona | банда |

- В каждой фракции 6 рангов: 6 — лидер, 5 — заместитель. Члены фракции спавнятся на её базе (если есть свой дом, то у дома).
- `/duty` у значка футболки на базе: надеть форму и получить оружие (полиция ещё и бронежилет). Ещё раз `/duty`, чтобы снять.
- `/f [текст]` — рация фракции, `/members` — кто онлайн, `/fleave` — уйти из фракции.
- Лидер и зам: `/invite [id]` (игрок соглашается через `/accept`), `/uninvite [id]`, `/giverank [id] [ранг]`.
- **Полиция** (на смене): `/su [id] [1-6] [причина]` — объявить в розыск, `/wanted` — список, `/clear [id]` — снять розыск, `/cuff` и `/uncuff [id]` — наручники, `/putcar [id]` — посадить задержанного в патрульную машину (сидя за рулём), `/arrest [id]` у участка — в тюрьму на 5 минут за каждую звезду (полицейский получает премию), `/m` — мегафон.
- **Медики** (на смене): `/heal [id]` — предложить лечение, пациент соглашается через `/accept`.
- Полиция и медики получают на PayDay зарплату фракции: $300 + $100 за ранг. Машины фракции может водить только её член.
- Розыск и срок в тюрьме сохраняются: если выйти с сервера, после входа досидишь.

**Админ-команды фракций:**

| Команда | Уровень | Что делает |
|---|---|---|
| `/jail [id] [минуты] [причина]` | 2 | Посадить в тюрьму |
| `/unjail [id]` | 2 | Выпустить |
| `/makeleader [id] [фракция 1-5]` | 4 | Назначить лидера |
| `/setfaction [id] [фракция 0-5] [ранг]` | 4 | Поставить во фракцию (0 — убрать) |
| `/setfspawn [фракция]` | 4 | Перенести спавн фракции туда, где стоишь |
| `/setfduty [фракция]` | 4 | Перенести раздевалку (/duty) туда, где стоишь |
| `/addfcar [фракция]` | 4 | Сделать машину из `/veh` машиной фракции (там, где она стоит) |
| `/delfcar` | 4 | Удалить машину фракции, в которой сидишь |

Координаты баз банд и машин примерные. Если точка стоит неудобно, перенеси её командами выше: всё сохраняется в базу.

**Кнопки** (команды тоже работают):

| Кнопка | Где | Что делает |
|---|---|---|
| **ALT** | пешком | Действие рядом: войти или выйти из дома, купить дом (с подтверждением), банкомат, магазин или свой бизнес, раздевалка фракции, работа, автосалон, шлагбаум |
| **ALT** | у игрока | Меню взаимодействия с тем, кто стоит перед тобой: передать деньги, показать номер, пожать руку. Лидеру: пригласить во фракцию. Полиции: наручники, обыск. Медику: лечение. Если держишь игрока на прицеле (ПКМ), меню откроется для него |
| **Y** | везде | Принять предложение или ответить на звонок |
| **N** | везде | Отказаться или сбросить звонок |
| **2** | за рулём | Двигатель |
| **H** | за рулём | Открыть шлагбаум или ворота своей фракции (закроются сами через 6 секунд) |

Сервер видит только игровые кнопки GTA, поэтому E, L и цифры 1–9 назначить нельзя. Подсказки «ALT — войти» написаны над точками.

Шлагбаумы и ворота ставит админ 4+: `/addgate [фракция 0-5] [1 шлагбаум / 2 ворота]` там, где стоит (0 — открывают все), `/delgate` удаляет ближайший. Один шлагбаум LSPD стоит по умолчанию, координаты примерные. Полиция может обыскать: `/frisk [id]`. Отказаться от предложения: `/deny`.

**Районы банд** (`/turfs` — список): цветные квадраты на радаре — районы Grove, Ballas и Aztecas, серые — ничьи.
- Член банды ранга 3+ встаёт в чужой район и вводит `/capture`. Захват идёт 5 минут, район мигает у всех.
- Очки: +1 за каждое убийство врага в районе и +1 за каждого живого бойца в районе в конце. У нападающих больше — район их, ничья — остаётся у защитников.
- На один район можно нападать раз в 30 минут. Захват разрешён с 16:00 до 24:00 (меняется в `config.inc`).
- Каждый PayDay члены банды онлайн получают $150 за каждый район банды.

**Банк:** у банкомата (зелёный значок $ или аппарат) нажми ALT или введи `/bank`: баланс и номер счёта, положить, снять (комиссия 1%), перевести игроку по id или по номеру счёта (даже если он не в игре), история последних 10 операций. Зарплата на PayDay приходит на счёт, на остаток капают проценты (0.1% в час, не больше $500). Деньги в банке не теряются при смерти. Все цифры — в `config.inc`, раздел «Банк».

**Телефон:** покупается в магазине 24/7 через `/buy` ($500), номер выдаётся сам. `/number` — свой номер, `/number [id]` — узнать номер человека рядом, `/call [номер]` — позвонить, `/p` — ответить, `/h` — положить трубку, `/sms [номер] [текст]`, `/911 [что случилось]` — вызов полиции и медиков на смене. Во время разговора обычный чат слышит и собеседник.

**Бизнесы:** у значка «i» введи `/buy`, чтобы купить товар. Магазин 24/7 продаёт телефон, аптечку и биту, бар — еду и напитки для здоровья, Binco — одежду (новый скин сохраняется), Ammu-Nation — оружие с 2 уровня. Бизнес можно купить через `/buybiz`. Тогда владельцу в кассу идёт половина от каждой покупки и $200 каждый PayDay. `/bizcash` — забрать кассу, `/bizinfo` — информация, `/sellbiz` — продать за полцены.

**Админ-команды (новые):**

| Команда | Уровень | Что делает |
|---|---|---|
| `/addturf [размер] [название]` | 4 | Новый район банд (квадрат вокруг тебя) |
| `/setturf [0/3/4/5]` | 4 | Отдать район банде (0 — ничей) |
| `/delturf` | 4 | Удалить район, в котором стоишь |
| `/addatm`, `/delatm` | 4 | Поставить банкомат (аппарат появится перед тобой) или удалить ближайший |
| `/createbiz [тип 1-4] [цена] [название]` | 4 | Создать бизнес там, где стоишь |
| `/delbiz` | 4 | Удалить бизнес рядом |

### Два сервера: Peace и War

Пока оба сервера работают на одном и том же моде без различий. Чтобы запустить второй, скопируй всю папку `C:\openmp\Server` в `C:\openmp\ServerWar`, а в его `config.json` смени `"port": 7777` на `7778` и `"name"` на `"Bastion Online | War"`. У каждого сервера будет своя база игроков.

**PayDay:** каждый час в :00 по времени компьютера сервера — $500 и +1 опыт. Опыта на следующий уровень нужно `уровень × 4`.

**Администрация** (`admin.inc`). Уровни: 1 — хелпер, 2 — модератор, 3 — администратор, 4 — ст. администратор, 5 — гл. администратор. В игре: `/ahelp`.

| Команда | Уровень | Что делает |
|---|---|---|
| `/a [текст]` | 1 | Чат админов (с пометкой уровня и [моб] у игроков с телефона) |
| `/amenu` | 1 | Панель в окнах: список игроков → телепорт, слежка, проверка, наказания. Удобно с телефона |
| `/reports`, `/ans [№] [ответ]` | 1 | Репорты игроков: список, взять, ответить, закрыть |
| `/check [id]` | 1 | Платформа, пинг, FPS, варны, мут, деморган (IP — с 3 уровня) |
| `/spec [id]`, `/specoff` | 1 | Следить за игроком и вернуться на место |
| `/goto [id]` | 1 | Телепорт к игроку |
| `/kick [id] [причина]` | 1 | Кикнуть |
| `/mute [id] [минуты] [причина]`, `/unmute` | 1 | Мут чатов (/me, /b, /pm, /f, /sms...), держится после перезахода |
| `/warn [id] [причина]` | 2 | Предупреждение. 3 варна — автобан на 3 дня |
| `/ajail [id] [минуты] [причина]`, `/unajail` | 2 | Деморган: отдельная камера, срок идёт и после перезахода |
| `/freeze`, `/unfreeze`, `/slap [id]` | 2 | Заморозить / подкинуть |

| `/sethp [id] [0-100]` | 2 | Здоровье |
| `/setskin [id] [скин]` | 2 | Сменить скин (сохраняется) |

| `/alog [ник]` | 3 | Последние 20 действий админов (все или по нику) |
| `/veh [модель] [цвет1] [цвет2]`, `/dveh` | 3 | Создать / удалить машину |

| `/fpslist` | 1 | FPS всех игроков |

| `/setweather [0-45]` | 3 | Погода |
| `/addtp [название]`, `/deltp [название]` | 4 | Сохранить точку там, где стоишь / удалить |

Точки хранятся в таблице `teleports`. При первом запуске туда записываются: spawn, cityhall, autoschool, lspd, hospital, port, unity, idlewood, lsair, sf, sfair, lv, lvair, chiliad. Античит: джетпак у игрока без админки — кик с записью в лог.

Все наказания, выдачи денег, админок и ответы на репорты пишутся в таблицу `admin_log` базы `rp.db`, репорты — в `reports`. Баны со сроком снимаются сами при следующем входе. Бан по IP не используется: у мобильных операторов один IP на множество игроков.

### FPS выше 90

SA-MP сам не даёт больше 90 FPS. 120 / 144 / 165 игроку включает **лаунчер** (пакет FPS с фиксами физики, см. `launcher/fps/README.txt`), сервер тут ничего не включает. Сервер только меряет настоящий FPS каждого игрока: `/fps` — свой, `/fps [id]` — чужой, `/fpslist` — всех (админам).

Если захочешь честный потолок (например, на War), поставь в `config.inc` `#define FPS_MAX_ALLOWED 165`: у кого FPS выше дольше 30 секунд, того предупредит и кикнет. По умолчанию `0` — без ограничений.

## 8. Как устроен код

Все файлы лежат в `gamemodes`:

```
rp.pwn            ← главный файл: подключает модули и принимает события сервера
bastion/config.inc     ← НАСТРОЙКИ: деньги, координаты, цвета, номера окон
bastion/base.inc    ← данные игрока (enum E_PLAYER), деньги, разбор параметров команд
bastion/database.inc   ← открытие базы и создание таблиц
bastion/accounts.inc   ← регистрация, вход, загрузка и сохранение
bastion/vehicles.inc   ← двигатель, автосалон, личные машины
bastion/houses.inc     ← дома
bastion/jobs.inc       ← работы
bastion/factions.inc   ← фракции, розыск, тюрьма
bastion/turfs.inc      ← районы банд и войны
bastion/bank.inc       ← банк и банкоматы
bastion/phone.inc      ← телефон
bastion/business.inc   ← бизнесы
bastion/gates.inc      ← шлагбаумы и ворота
bastion/keys.inc       ← кнопки ALT, Y, N, H, 2 и меню взаимодействия
bastion/fps.inc        ← замер FPS игроков, /fps, /fpslist, лимит FPS_MAX_ALLOWED
bastion/chat.inc       ← RP-чат
bastion/admin.inc      ← админ-команды
bastion/commands.inc   ← /help, /stats, /pay и ГЛАВНЫЙ СПИСОК КОМАНД
```

**Главные понятия Pawn:**
- **callback** (`public OnPlayerConnect(playerid)`) — функция, которую вызывает сервер, когда что-то случилось: игрок зашёл, написал в чат, сел в машину. Все callbacks собраны в `rp.pwn`, и каждый просто вызывает нужный модуль.
- **native** (`SetPlayerPos`, `GivePlayerMoney`) — функция сервера, которую вызываешь ты.
- **stock** — твоя обычная функция.
- **enum + массив** — так хранятся данные: `Player[playerid][pMoney]` — деньги игрока.

**Как игрок попадает в игру:**
1. `OnPlayerConnect` → `Account_OnConnect` проверяет ник и ищет аккаунт в базе.
2. `OnPlayerRequestClass` → включаем режим наблюдения (игрок ещё не в мире), показываем вид на город и окно входа/регистрации.
3. `OnDialogResponse` → `Account_OnDialog` проверяет пароль (сравнивает хеши) или создаёт аккаунт.
4. `Account_FinishLogin` → выдаёт деньги, загружает машину, задаёт место спавна и выключает режим наблюдения — игрок появляется.
5. `OnPlayerDisconnect` → `Account_Save` сохраняет всё в базу.

**База данных** — таблицы `accounts` (игроки), `houses` (дома), `vehicles` (личные машины), `factions` (базы фракций), `fvehicles` (машины фракций), `turfs` (районы), `atms` (банкоматы), `bank_log` (история операций по счетам), `businesses` (бизнесы), `gates` (шлагбаумы), `bans` (баны). Новые колонки в старую базу добавляются сами при запуске. Запросы пишутся так:

```pawn
DB_FreeResultSet(DB_ExecuteQuery(gDB, "UPDATE accounts SET money = %d WHERE id = %d", 100, Player[playerid][pDbId]));
```
`%d` — число, `%f` — дробное, `%q` — текст (безопасно экранируется). `DB_FreeResultSet` обязателен.

**Деньги** меняй только через `GiveMoney(playerid, сумма)` (минус — забрать). Сервер хранит свою сумму, поэтому чит на деньги ничего не даст.

## 9. Важно: кодировка (русский текст в игре)

Клиент SA-MP понимает русский только в кодировке **Windows-1251**. Все файлы мода уже сохранены в ней.

- Открывай их в **Notepad++**. Если вместо русского видишь «РџСЂРёРІРµС‚» или «������», выбери в меню **Кодировки → Кириллица → Windows-1251** (не «Преобразовать», а просто выбрать).
- Новые файлы сохраняй тоже в Windows-1251.
- Если сохранить в UTF-8, в игре вместо русского будут непонятные символы.
- Чтобы русский текст отображался у игроков, у них должен стоять русификатор или шрифт с кириллицей в SA-MP (у большинства русскоязычных игроков он уже есть). Чат, окна и надписи над домами используют шрифт Windows и показывают русский нормально.

## 10. Как расширять: три примера

### Пример 1. Новая команда `/hello`

В `bastion/commands.inc` добавь функцию перед `Commands_Process`:

```pawn
stock bool:Cmd_Hello(playerid)
{
	SendClientMessage(playerid, COLOR_GREEN, "Привет, %s! У тебя $%d.", GetRPName(playerid), GetMoney(playerid));
	return true;
}
```

И строку в `Commands_Process` рядом с остальными:

```pawn
	if (!strcmp(cmd, "/hello", true))       { Cmd_Hello(playerid); return 1; }
```

F5 → перезапусти сервер → в игре `/hello`.

### Пример 2. Команда с параметрами `/dice [ставка]`

```pawn
stock bool:Cmd_Dice(playerid, const params[])
{
	new pos = 0, bet;
	if (!NextIntParam(params, pos, bet) || bet < 1)
		return SendClientMessage(playerid, COLOR_GREY, "Использование: /dice [ставка]");
	if (GetMoney(playerid) < bet) return SendClientMessage(playerid, COLOR_GREY, "Не хватает денег.");

	if (random(2) == 0)
	{
		GiveMoney(playerid, bet);
		SendClientMessage(playerid, COLOR_GREEN, "Ты выиграл $%d!", bet);
	}
	else
	{
		GiveMoney(playerid, -bet);
		SendClientMessage(playerid, COLOR_RED, "Ты проиграл $%d.", bet);
	}
	return true;
}
```
В `Commands_Process`: `if (!strcmp(cmd, "/dice", true)) { Cmd_Dice(playerid, cmdtext[pos]); return 1; }`

Помощники для параметров (в `base.inc`): `NextPlayerParam` — id игрока, `NextIntParam` — число, `NextParam` — слово, `RestParam` — весь остаток текста.

### Пример 3. Новое сохраняемое поле (например, номер телефона)

1. В `base.inc` в `enum E_PLAYER` добавь `pPhone,`.
2. Добавь колонку в базу. В `database.inc` после создания таблиц:
   ```pawn
   DB_FreeResultSet(DB_ExecuteQuery(gDB, "ALTER TABLE accounts ADD COLUMN phone INTEGER DEFAULT 0"));
   ```
   (при повторных запусках SQLite ответит, что колонка уже есть — это нормально и ни на что не влияет).
3. В `accounts.inc` в `Account_Load` добавь `phone` в SELECT и `Player[playerid][pPhone] = DB_GetFieldInt(r, 6);`
4. В `Account_Save` добавь `phone = %d` и `Player[playerid][pPhone]`.

### Как узнать координаты для новых точек

Встань в нужное место в игре и введи `/save` (встроенная команда клиента SA-MP). Координаты запишутся в файл `Документы\GTA San Andreas User Files\SAMP\savedpositions.txt`. Их можно вставить в `config.inc`, `jobs.inc` (например, точки грузчика) или `vehicles.inc`.

> Часть координат (двери домов на Grove Street, точки в порту, мопеды у пиццерии, место выдачи машины в автосалоне) поставлены по памяти и могут быть смещены на несколько метров. Если пикап висит в стене или машина появляется неудачно, поправь координаты через `/save`.

## 11. Как пустить друзей

- **По локальной сети / через Radmin VPN или ZeroTier** — самый простой способ: друзья подключаются к твоему IP в этой сети, порт 7777.
- **Через интернет с домашнего ПК** — нужно пробросить порт **7777 UDP** в роутере на свой компьютер и дать друзьям внешний IP. Сервер работает, только пока включён твой ПК.
- **Хостинг** — для постоянного онлайна арендуй SA-MP/open.mp хостинг или VPS (Linux версия open.mp тоже есть). Загрузи туда папку сервера с `rp.amx`, `config.json` и `scriptfiles`.

## 12. Частые проблемы

| Проблема | Решение |
|---|---|
| Сервер сразу закрывается | Запусти `omp-server.exe` из командной строки, чтобы увидеть ошибку. Чаще всего: rcon-пароль `changeme`, или в `main_scripts` нет `rp 1`, или не скомпилирован `rp.amx` |
| `cannot read from file: "bastion/config.inc"` | Папка `bastion` должна лежать в `gamemodes` рядом с `rp.pwn` |
| Кракозябры вместо русского | Файлы пересохранены в UTF-8. Верни Windows-1251 (раздел 9) |
| Кикает сразу после входа | Ник без подчёркивания. Нужен `Имя_Фамилия`. Отключить проверку: `REQUIRE_RP_NAME false` в `config.inc` |
| Забыл пароль от аккаунта | Открой `scriptfiles/rp.db` в DB Browser for SQLite и удали строку игрока из `accounts` (при выключенном сервере) |
| Не могу подключиться | Сервер запущен? Адрес `127.0.0.1:7777`? Версия GTA 1.0? |
