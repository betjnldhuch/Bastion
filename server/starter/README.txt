Bastion Server — стартер сервера open.mp

Как поставить: положи BastionServer.exe в папку сервера (рядом с omp-server.exe,
например C:\openmp\Server) и запусти. Если положишь в другое место — укажи папку
во вкладке «Настройки».

Шапка: СТАРТ / РЕСТАРТ / СТОП, состояние, онлайн, аптайм.
Консоль: живой log.txt сервера, строка для консольных команд, список игроков.
Обновление мода: свежий rp.amx с GitHub одной кнопкой, компиляция rp.pwn
  через Qawno, rp.amx из файла, откат на прошлый rp.amx. Перед заменой мода
  стартер сам сохраняет rp.amx (gamemodes\backup) и базу (scriptfiles\backup).
Настройки: название, слоты, порт, пароли и прочее из config.json;
  автоперезапуск при падении, автостарт сервера, запуск вместе с Windows.

Крестик при работающем сервере: «Да» — остановить и выйти, «Нет» — свернуть в трей.
Свои настройки стартер хранит в BastionServer.ini рядом с exe.
Для второго сервера (War) положи копию стартера в его папку.
